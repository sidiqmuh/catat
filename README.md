# CATAT

Pencatat pengeluaran & pemasukan harian, tersambung ke Google Sheets lewat Apps Script.

- Ubah tampilan/fitur: edit `index.html` → Commit → Netlify memperbarui situs otomatis.
- Ikon ada di `icons/`, nama & warna aplikasi di `manifest.webmanifest`.
- Kode Apps Script (berisi PIN) **tidak** disimpan di repo ini.
